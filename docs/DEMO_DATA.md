# Demo data

Every demo record is fictional and was constructed for this public repository. Names use Alex Example, Morgan Example, generically named children, and a fictional pet. Email addresses use the reserved `example.invalid` domain. Events, tasks, meals, groceries, routines, documents, fitness records, finance records, and Home Assistant entities do not describe the original household.

The demo never seeds medicine dosages or personalised medical advice and never calls an external provider. `make reset-demo` destroys only the Compose demo volume and `make demo` recreates the deterministic fixture with a locally generated password.
