# Project history

HausKlar was developed privately before this public release. Broad milestones in the private repository show an initial family-planning backend and native client, expansion into offline sync and the web client, then deeper household, document, assistant, Fitness, Finance, security, and operational work. These are historical private-development milestones, not activity reconstructed in this public Git repository.

Private commit messages are not reproduced because they can contain household and infrastructure context. The public Git history begins with a sanitised source release so that deleted private material cannot be recovered from Git objects.
