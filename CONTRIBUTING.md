# Contributing

Open an issue before large changes. Keep the planner central, preserve iOS/PWA parity, and use synthetic `.invalid` identities in tests and docs. Never commit real household data, credentials, deployment endpoints, signing material, screenshots, databases, or uploaded files.

Run `make test` and `make audit`. Add tests for changed behaviour, especially offline sync, authorisation, owner boundaries, assistant proposals, uploaded files, and medicine reminders. Use conventional commit messages and certify that contributed material may be licensed under Apache-2.0.
